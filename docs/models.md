# 模型与表情

「模型」页面包含模型库、表情、动作、绑定和图层。控制台用于日常切换，模型页面用于编辑。

## 管理模型库

点击封面加载模型。导入模型后，如果列表没有更新，可点击底部「重新扫描」。底部的「打开模型目录」用于查看模型存放位置。

右键点击模型可打开位置、重命名、重新生成封面或删除模型。键盘可使用菜单键或 Shift+F10 打开菜单。重新生成封面时留意软件提示，部分情况需要切换当前模型。

删除前核对模型名称与目录，并保留自己的原始资源备份。

## 新建与编辑表情

在「模型 → 表情」中创建或编辑表情。弹窗按参数列出启用状态、参数名和数值：选中需要覆盖的参数，再设置目标值，保存后回到控制台使用。

放弃会退出当前编辑；删除表情是独立操作，需要确认。表情效果取决于模型自身提供的参数，软件不能凭空增加模型没有的部件或表情。

## 动作与快捷键

在「模型 → 动作」中编辑动作快捷键；日常播放在控制台进行。该编辑页不提供动作内容制作或删除。可用动作来自模型已有资源。

如果切换表情后与面捕效果冲突，先取消表情再观察；确认哪些参数由表情覆盖，哪些应继续跟随面捕。

## 绑定和图层

「绑定」决定输入怎样驱动模型参数，见[转换与绑定](binding.md)。「图层」用于调整当前模型的图层设置；修改前确认选中的部件，逐项观察预览效果。

模型运行使用自有 `.uvtb` 档案。迁移旧绑定时，需要主动选择文件导入，普通加载不会自动读取 `.vtube.json`。
