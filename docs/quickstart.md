# 快速开始

先让模型动起来，再调整画面和细节。建议第一次设置时暂不开始直播。

## 准备好模型和设备

你需要 Windows 电脑、一份有权使用的 Live2D 模型，以及可用的摄像头或受支持的 iPhone 面捕来源。模型文件应保留完整资源目录，不能只移动一个描述文件而丢掉纹理、动作等配套资源。

## 1. 导入并加载模型

进入「模型 → 模型库」，点击「导入模型」，通过文件选择器选择受支持的模型。已有模型也可以通过「打开模型目录」检查位置，再点击「重新扫描」。点击模型封面加载它。

控制台顶部会显示当前模型名称。一次显示一个主模型；切换模型后，先检查预览，再继续调整。

## 2. 连接面捕

进入「面捕 → 连接」，选择当前可用的面捕来源。使用摄像头时，选择摄像头和工作帧率，再点击「启动面捕」。需要更换设备时先关闭面捕。

使用 iPhone 来源时，操作入口显示「启动监听」。电脑端监听启动并不表示已经收到手机数据，须确认连接状态。详细步骤见[连接面捕](tracking.md)。

## 3. 完成矫正

加载模型并启动面捕后，面向镜头、保持自然姿态，点击「面捕矫正」。缓慢转头、眨眼和张嘴，观察模型是否正常响应。更换输入来源后重新矫正。

## 4. 设置输出

进入「设置」，打开「预览窗口」，确认模型画面。按需要设置分辨率与 30 / 60 渲染帧率；接入支持 Spout2 的直播软件时打开「Spout2」。
