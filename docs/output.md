# 直播输出与截图

输出设置位于「设置」页面。先在预览窗口确认模型，再接入直播软件。

## Spout2 输出

打开「Spout2」，然后在支持 Spout2 的接收程序中选择本应用输出。OBS 等软件需具备相应的 Spout2 接收支持；仅开启本应用开关不会自动安装接收插件或创建直播来源。

## 添加到 OBS

绘动通过 OBS 的 WebSocket 自动把 Spout2 来源加入当前节目场景。需要先启用 OBS WebSocket，并安装 OBS 的 Spout2 插件；两者分别负责添加来源和接收画面。

1. 在 OBS 中打开「工具」→「WebSocket 服务器设置」，勾选「启用 WebSocket 服务器」并应用。OBS 28 及以上通常已内置 WebSocket；建议保留身份验证，绘动会读取本机设置，无需另行填写密码。
2. 从 [OBS Spout2 插件发布页](https://github.com/Off-World-Live/obs-spout2-plugin/releases)下载适用于当前 OBS 版本的插件，按照发布页的安装说明操作，然后重启 OBS 使插件加载。安装的是 OBS 插件，不只是 Spout2 软件本身。
3. 打开 OBS 并选好节目场景，在绘动的「设置」中点击「添加到 OBS」。绘动会添加或启用来源并打开 Spout2 输出。工作室模式下请检查节目场景。

如果提示无法连接 WebSocket，请检查 OBS 是否正在运行、服务是否启用；如果提示找不到 Spout2 来源，请检查插件是否正确安装并在重启后加载。若来源已添加但没有画面，检查绘动是否正在运行以及两端是否使用同一显卡。便携版 OBS 或通过启动参数覆盖 WebSocket 设置时，自动读取的本机设置可能与实际设置不同。

找不到来源时，确认本应用正在运行、Spout2 已开启、接收端支持 Spout2；双显卡电脑还应检查两个程序使用的显卡是否一致。

当前「添加到直播姬」属于准备中入口，不能作为已可用的一键接入功能。

## 分辨率、帧率与预览

分辨率选择器支持预设与宽高设置；应用后影响渲染输出。渲染帧率可选 30 或 60。较高分辨率和帧率需要更多性能，直播时可先选择 30 帧并观察负载。

「预览窗口」控制本机预览显示，「预览尺寸」可选 25%、50%、100%。预览尺寸用于缩放预览窗口，不等同于降低输出分辨率。

## 导出图片

- 「截图 PNG」：导出当前画面的 PNG。
- 「全分辨率 PNG」：导出全分辨率模型图片，需要先加载模型。
- 「分层 TIFF」：导出分层图片，需要先加载模型；用支持相应 TIFF 图层的图像工具打开。

导出过程中等待完成提示，避免重复点击。图片结果应在目标软件中检查，尤其是透明背景与图层支持情况。

## 录制视频

在「设置」的录制区域，可以选择绿幕视频或透明视频，并在录制前确认保存位置。透明视频需要接收软件支持对应格式。
