# 转换与绑定

这两处设置解决不同的问题：面捕转换负责理解输入，模型绑定负责驱动当前模型。

## 面捕 → 转换

这里将原始 ARKit 系数转换为通用面捕参数。保留自动转换方案，也可以调整输入起始、输入结束、曲线中点以及输出起始、输出结束，并通过实时预览观察变化。

转换配置按来源保存。如果同一来源在多个模型上都出现相似的输入问题，先检查这里。

## 模型 → 绑定

这里将通用面捕参数对应到具体模型参数。每行对应一个参数，可调整目标输出、输出起始与结束，以及输出曲线。配置随模型档案保存。

优先选择曲线预设；选择「自定义」才打开独立弹窗编辑输出范围与曲线。不要同时大幅修改多行，先调整一个参数，观察完整动作范围，再继续。

## 一个排查顺序

1. 先取消可能覆盖参数的表情。
2. 检查面捕连接，完成自然姿态矫正。
3. 在转换页观察输入和输出，确认通用参数是否合理。
4. 在绑定页检查目标参数及范围，确认是否符合模型设计。

输入正常而模型张嘴幅度不合适时，重点检查该模型的嘴部绑定。输入本身就不稳定时，先检查来源、光照、矫正与平滑。

## 手动迁移旧配置

软件底层保留了主动导入 `.vtube.json` 的能力，可将支持的参数映射、表情热键和图层设置转换并保存到自己的 `.uvtb` 档案，不写回原文件。当前新版控制台尚未提供该导入入口，本说明书不将它列为可以直接点击完成的操作。

普通加载、扫描与封面生成不会自动读取旧配置。导入后可移动或删除该 JSON，但模型、表情等资源仍须保留。外部平滑数值会转换为自身的平滑设置，不保证与原应用效果完全一致；导入后请检查表情、快捷键和姿态并重新矫正。
