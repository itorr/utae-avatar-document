# 从这里认识你的虚拟形象

utae avatar 是面向 Windows 的轻量 Live2D 动捕展示软件。加载一个主模型，连接面捕，在控制台切换表情与动作，再把形象输出到直播画面。

第一次使用，按照下面的顺序操作即可。

1. [快速开始](quickstart.md)：从加载模型到看到形象动起来。
2. [模型与表情](models.md)：管理模型、表情、动作和图层。
3. [连接面捕](tracking.md)：选择摄像头或 iPhone 来源并完成矫正。
4. [转换与绑定](binding.md)：把面部动作变成适合自己模型的表现。
5. [直播输出与截图](output.md)：设置 Spout2、分辨率和图片输出。
6. [设置与性能](settings.md)：调整主题、启动行为和画质。
7. [常见问题](faq.md)：按出现的问题逐项排查。
8. [使用声明](terms.md)：开发方与 Live2D 声明。

本文档对应 2026 年 10 月 23 日核对的桌面控制台。不同版本的可用来源、设备和模型资源可能不同，请以当前软件实际显示为准。
