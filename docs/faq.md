# 常见问题

## 模型没有出现在列表中

在模型库点击「重新扫描」。通过「打开模型目录」确认资源位置；导入时保留完整模型文件与配套目录。只有图片不是可驱动的 Live2D 模型。

## 摄像头下拉框为空或无法选择

先停止面捕，再点击摄像头旁边的刷新图标。检查 Windows 摄像头权限、设备连接和是否被其他程序占用。面捕运行中禁止切换来源和设备是正常行为。

## iPhone 已启动监听，但模型不动

启动监听只代表电脑准备接收。确认使用兼容的手机发送端、手机与电脑可互通、端口一致以及防火墙允许接收。查看是否真正显示已连接，再检查模型是否已加载。

## 模型歪头，或更换设备后姿态不对

面对镜头保持自然姿态，重新做「面捕矫正」。iPhone 来源按需要做「水平校准」。不同来源的中性姿态不能直接当作同一套校准使用。

## 表情正确，但一开面捕就不自然

先取消已启用的表情，检查转换输出与模型绑定范围。详见[转换与绑定](binding.md)。不要同时修改多个来源和模型参数，否则难以判断是哪项变化产生影响。

## 直播软件找不到画面

确认 Spout2 开关已开启，接收软件具有对应支持并选中了正确来源。查看本机预览是否正常；多显卡设备检查两端显卡设置。详见[直播输出与截图](output.md)。

## 导入旧配置后效果与以前不完全相同

导入是一次性转换可支持的数据，不是运行原应用。平滑和姿态处理存在差异，请重新矫正并检查绑定范围。原始模型与表情资源必须保留。
