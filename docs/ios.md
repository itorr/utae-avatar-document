# 绘动面捕（iPhone）

用带 TrueDepth 摄像头的 iPhone 捕捉面部表情和头部姿态，通过局域网发送给 Windows 上的绘动 edo，驱动 Live2D 形象。iPhone 端需要 iOS 16 或更新版本，首次使用请允许相机和本地网络权限。

## 连接电脑

1. 将 iPhone 和 Windows 电脑接入同一可信局域网。
2. 在绘动 edo 打开「面捕 → 连接」，将「面捕来源」设为「苹果手机」，打开「允许自动发现」，再点击「启动监听」。
3. 在 iPhone 上打开面捕 App，点「自动发现」。如果搜索不到电脑，手动填写电脑的局域网 IP 和电脑端显示的接收端口（默认 39540），再点「开始发送」。
4. 正对 iPhone 的前置摄像头，保持约 40–70 厘米距离。以电脑端的接收状态为准。模型加载后，可在电脑端做「面捕矫正」。

面捕运行时，iPhone 会保持屏幕常亮，可在运行页调低亮度。设备温度过高时，App 会降低高帧率档位的采集频率。请将 App 保持在前台。

## 使用麦克风辅助嘴型

1. 开始面捕后，在 iPhone 上点「麦克风辅助」，允许麦克风权限。
2. 在绘动 edo 的「面捕 → 连接 → 语音辅助」打开「麦克风嘴型」，将「输入设备」选为「iPhone 麦克风」。
3. 说话并观察模型的嘴型，按需要调整「噪声门」和「张口比例」。

关闭 iPhone 的麦克风辅助或停止面捕即可停止音频传输。

## 技术支持

如果自动发现失败，检查 iPhone 的本地网络权限、电脑是否已启动监听，以及 Windows 防火墙是否允许绘动 edo 接收数据。如果手动连接也失败，确认 IP 和端口正确，并检查所用网络是否隔离设备。
