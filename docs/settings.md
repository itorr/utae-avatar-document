# 设置与性能

## 语言与主题

语言可选自动、中文、日本語和 English；自动跟随系统。主题使用色块选择，默认粉色，也可切换其他配色。语言和主题属于界面偏好，不会改变模型名称或绑定内容。

## 启动行为

- 「记住模型」：控制下次启动时是否恢复上次模型。
- 「自动启动面捕」：按已配置的来源自动开始面捕。
- 「记住表情动作」：保留模型的表情动作状态。

首次使用先手动完成模型和设备配置，确认工作正常后再开启自动行为。

## 画质和运行

「优化模型加载」用于模型加载优化。「纹理分辨率」可选 25%、50%、100%；降低它会牺牲细节，适合性能受限时尝试。

画质设置还包含物理帧率、物理强度、纹理过滤与遮罩相关设置。物理影响头发、衣物等由模型定义的运动。修改时一次只改一项，观察是否改善目标问题。

## 直播时的调整顺序

先降低渲染帧率或输出分辨率，再视情况降低纹理分辨率。面捕工作帧率与渲染帧率分别调整，避免只减少一项却误以为所有处理频率都降低。

模型复杂度、输出尺寸、设备和其他运行中的程序都会影响表现，本站不提供未经实测的占用或延迟保证。

部分滑块支持双击恢复默认值。恢复前记下自己的调整结果，避免丢失希望保留的配置。
